# Uniquad User Manual

The end-user manual for Uniquad, with one file per module. It is written for staff who work in the Desk and for applicants, students, faculty and parents who use the portals. Steps are numbered, and the labels you click are in **bold**.

> **Source of truth:** this folder is a Markdown export of the online *Uniquad — User Manual* (last export 2026-11-26). The online version also has about 215 screenshots. Here each one is a `Screenshot:` placeholder. Edit the online manual first, then export it again.
