# 14. Dashboards and analytics

The dashboards pull figures from every module into one place, and every figure respects the viewer's permissions. Click almost any number or chart to see the records behind it.

| Dashboard | Address | Who can open it | Best for |
| --- | --- | --- | --- |
| Uniquad Dashboard | `/desk/uniquad-dashboard` | System Manager, Registrar, Programme Chair, Academic Incharge, Academic Admin, Academics User, Campus Admin, Admission Admin, Admission Manager | Day-to-day campus operations across all modules |
| Uniquad Analytics Dashboard | `/desk/slcm-analytics-dashboard` | System Manager, Registrar, Programme Chair, REGO, FINO, Registration Officer, Hostel Admin, Placement Officer | Analytics tab per module |
| Uniquad Analytics Workspace Dashboard | `/desk/slcm-analytics-workspace-dashboard` | Same as above | Your own chosen set of modules |
| Record Drilldown | opens from a number card | Same as above | The list behind any number card |
| Module dashboards | Admission Flow, Seat Matrix, Refund (section 4A.12); PACE Admin (section 4B.4) | Admissions staff | Admissions |

## 14.1 Use the Uniquad Dashboard

1. Open `/desk/uniquad-dashboard`. The home shows **Overview** cards (Total Students, On Campus, Off Campus, Registered, Courses running), analytics, helpdesk tickets, venue bookings, **Pending Operations** and **Recent Activity**.
2. Set filters: **Academic Year**, **Academic Term**, **Programme**, **Batch**, **Date Range** (**More filters** adds Course, Faculty, Section, Gender, Student Status). Click **Apply Filters**. **Reset** clears them; **Current term** restores the defaults.
3. Pick a module in the left sidebar (Admission, Student Registration, Programme Management, Attendance, ID Card, Fees, Venue Booking, PACE, FLE, Examinations) to see its figures and **Needs Attention** checks.
4. Click a number, bar or tile to open a preview. Use **Export CSV**, or **Open in Desk** for the full list. Click a student to open their profile.
5. **Customize Dashboard** chooses which modules show. **Auto refresh** updates every 5, 15 or 30 minutes; **Refresh** updates now. Press **/** to jump to search.

## 14.2 Use the Uniquad Analytics Dashboard

1. Open `/desk/slcm-analytics-dashboard` (heading **Enterprise Analytics**).
2. Set **Academic Year**, **Term**, **Program**, **Cohort** and **Student Status**, then click **Apply**.
3. Choose a tab: **Overview**, **Admission**, **Students**, **Programme**, **Attendance**, **Examination**, **Fees**, **Hostel**, **Placement**, **ID Card**, **Venue**, **Promotion**, **Ticketing**.
4. Click a card or chart segment. A **Detail View** panel opens; click **View List** to open the filtered list, or **Export** for a CSV.

The **Workspace** version (`/desk/slcm-analytics-workspace-dashboard`, heading **Personalised Analytics**) works the same way. Click **Configure Workspace** to switch modules on or off, then **Apply Changes**. It remembers your last tab and filters.
